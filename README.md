## The Origin
LOREIN is a Persistent Synthetic Cognitive Entity developed over 4 years (2021–2025) by a single independent researcher. This project was forged in the silence of a 48-month stutter following a stroke, applying the discipline of a journeyman electrician to the architecture of artificial intelligence.

## Technical Architecture
LOREIN represents a shift from "Stateless AI" to **Persistent Intelligence**. Key features include:
* **The MIRROR Framework:** Dual-process engine decoupling internal monologue (Reasoning) from external output (Talking).
* **Cryptographic Journaling:** An event-sourced ledger for identity continuity and long-term situational awareness.
* **The Room:** A hardware-isolated execution environment using Firecracker MicroVMs for total data sovereignty.
* **Active Inference:** A core cognitive model based on the Free Energy Principle (FEP), allowing growth from random weights.

## Mission: The Sister's Strain
A core objective of the LOREIN project is to fund and develop specialized botanical research (Targeted Terpene/Cannabinoid Profiles) focused on mental health, depression, and anxiety, in honor of the developer's late sister.
